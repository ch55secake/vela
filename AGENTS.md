# Agent guidelines

## README

- Keep the README concise and limited to essential, factual project, install,
  development, and release information.
- Do not add unrequested feature lists, implementation details, marketing copy,
  speculative plans, or filler.
- Only change it when the information is necessary for users to install, build,
  or release Vela, or when the user explicitly asks.
- Verify every README statement against the current code and release workflow.
